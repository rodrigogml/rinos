# Evidência 5.2.4 — bordas MFA, consentimento e recuperação

Os testes do componente RFW cobrem expiração e rejeição de desafio, reenvio com cooldown, provider indisponível, cancelamento de consentimento, alteração concorrente do catálogo, replay de passkey e resultado neutro. A operação pendente permanece ocupada e uma falha não limpa dados que não sejam explicitamente preserváveis.
