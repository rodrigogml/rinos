# Checklist de Requisitos — Participação em Contas

- [x] Cada FR da spec está roteada para modelo, contrato ou tarefa.
- [x] Papel não concede acesso e reentrada preserva ciclos anteriores.
- [x] Convite de 15 dias, prova única, substituição e e-mail confirmado estão modelados.
- [x] Plano e autorização permanecem motivos independentes.
- [x] Continuidade usa resultado efetivo e 2FA, não papel.
- [x] O primeiro slice não anuncia convite/lifecycle como entregue.
